# Contribuir

¡Gracias por querer mejorar el Personal OS! Issues y pull requests son bienvenidos.

- Antes de un cambio grande, abre una issue para hablarlo.
- Sigue el estilo del código que tocas y añade pruebas (`cd control-center/backend && env -u CC_DB_URL .venv/bin/pytest`).
- Documentación e interfaz en español.
- Nada de datos personales, claves ni tokens en el código, las pruebas o los ejemplos.
